    Shrinkage path: slope w as a function of λ (log scale)

    What is being minimised

    L(w, b) = Σᵢ (yᵢ − w xᵢ − b)² + λ w²

    With the intercept unpenalised, the solution is w = Sxy / (Sxx + λ) and b = ȳ − w x̄, where Sxx = Σ(xᵢ − x̄)². The slope reaches half its OLS value when λ = Sxx, which is shown in the panel beside it.

    This matches sklearn.linear_model.Ridge(alpha=λ), which uses the summed (not averaged) squared error and leaves the intercept unpenalised.
